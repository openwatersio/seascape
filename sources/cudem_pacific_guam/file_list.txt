# NOAA CUDEM, Guam — a *filelist* (manifest), not a data file: each line below is an NCEI
# urllist the engine fetches, 6 tiles in both published bands: 1/9 arc-second (~3.4 m, 8112²
# tiles) nearshore and 1/3 arc-second (~10 m, 2712² tiles) telescoping out beyond it. Build
# depth is derived per FILE from its own pixel size, so both bands live in one source.
# The two bands are in DIFFERENT horizontal frames — NAD83(MA11) (EPSG:6325, geographic 2D, no
# vertical component declared) at 1/9, NAD83 (EPSG:4269) at 1/3 — and they share a build depth,
# so they would meet in one VRT, which silently drops the off-frame inputs. Hence `mixed_crs`:
# the mosaic warps each input to the tile grid lazily instead. NoData -9999.
# The 1/3 headers declare NAVD88 height (EPSG:5703), which has no realization on Guam — NGS
# defines GUVD04 and CO-OPS publishes no NAVD88 at either Guam station — so the label is read
# as the local datum and gets the same +0.418 m as the 1/9 band. The vertical CRS is dropped at
# prep either way, so nothing warps against that declaration.
# One source per NCEI territory dataset because `datum_offset_m` is per-source and each
# territory sits on its own island datum; see sources/README.md for the station evidence behind
# +0.418 m (CO-OPS Apra Harbor 1630000, larger than Pago Bay's +0.308 m 15 km away — the larger
# is the bias-shallow-safe end of the range).
