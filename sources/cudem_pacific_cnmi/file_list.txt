# NOAA CUDEM, CNMI — a *filelist* (manifest), not a data file: each line below is an NCEI
# urllist the engine fetches, 10 tiles over Saipan, Tinian and Rota (lon 145.0..146.0, lat
# 14.0..15.5), in both published bands: 1/9 arc-second (~3.4 m, 8112² tiles) nearshore and 1/3
# arc-second (~10 m, 2712² tiles) telescoping out beyond it. Build depth is derived per FILE
# from its own pixel size, so both bands live in one source and the merge orders the finer
# files first. NAD83 (EPSG:4269) horizontal on every tile, nodata -9999.
# The headers declare NAVD88 height (EPSG:5703), which has no realization in the CNMI — NGS
# defines NMVD03 and CO-OPS publishes NMVD03, not NAVD88, at Saipan — so the label is read as
# the local datum. One source per NCEI territory dataset because `datum_offset_m` is
# per-source; see sources/README.md for the evidence behind +0.393 m (CO-OPS Saipan 1633227,
# the only station in the archipelago).
