# NOAA CUDEM 1/3 arc-second national topobathy — a *filelist* (manifest): one tile
# URL per line, ~370 tiles (~8.5 GB), ~10 m. The offshore/deeper band that telescopes
# out beyond the 1/9 nearshore zone (zero tile-cell overlap with cudem 1/9), plus the
# primary high-res Alaska coverage (98 tiles vs 16 in 1/9). NAVD88 / NAD83 (EPSG:4269)
# upstream, NoData -99999. Each tile is fetched, corrected onto MLLW against
# store/datum/navd88_mllw.tif (metadata `offset_surface`) and normalized to a COG —
# no build-time NOAA reads. Alaska outside the southeast panhandle has no VDatum grid,
# so those tiles stay on NAVD88.
https://noaa-nos-coastal-lidar-pds.s3.amazonaws.com/dem/NCEI_third_Topobathy_2014_8580/urllist8580.txt

# Territory topobathy (issue #32): Hawaii, Puerto Rico, USVI, Guam, American Samoa,

# PR=PRVD02, USVI=VIVD09, and the Pacific offshore band (Guam/AmSam/CNMI) is labeled
