# NOAA CUDEM 1/3 arc-second national topobathy — a *filelist* (manifest): each line is
# an NCEI urllist the engine fetches, 417 tiles at ~10 m. The offshore/deeper band that
# telescopes out beyond the 1/9 nearshore zone (zero tile-cell overlap with cudem 1/9),
# plus the primary high-res Alaska coverage (98 tiles vs 16 in 1/9) and Puerto Rico /
# USVI. Each tile is fetched, corrected onto MLLW against store/datum/navd88_mllw.tif
# (metadata `offset_surface`) and normalized to a COG — no build-time NOAA reads.
# NAD83 (EPSG:4269) horizontal throughout, which is what lets the whole source mosaic
# through one VRT; vertical is NAVD88, or PRVD02/VIVD09 in PR/USVI (both ≡ LMSL, so
# VDatum's `S = −mllw` branch corrects them with the rest). Alaska outside the southeast
# panhandle has no VDatum grid, so those tiles stay on NAVD88. NoData varies per tile
# (-9999 / -99999 / -999999) and each file's header carries it.
# Hawaii, Guam, CNMI and American Samoa are their own source (cudem_pacific_third).
