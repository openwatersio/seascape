# NOAA CUDEM 1/9 arc-second national topobathy — a *filelist* (manifest), not a
# data file: one tile URL per line, ~940 tiles across all 18 US coastal regions
# (Atlantic, Gulf, Pacific, AK). Each tile is fetched, corrected onto MLLW against
# store/datum/navd88_mllw.tif (metadata `offset_surface`) and normalized to a COG —
# no build-time NOAA reads. NAVD88 vertical / NAD83 (EPSG:4269) horizontal upstream.
# NOAA regenerates the manifest as tiles are re-surveyed, so coverage stays current
# without re-listing here.
https://noaa-nos-coastal-lidar-pds.s3.amazonaws.com/dem/NCEI_ninth_Topobathy_2014_8483/urllist8483.txt

# Territory topobathy (issue #32): Hawaii, Puerto Rico, USVI, Guam, American Samoa,
# CNMI — same NCEI bucket family, same COG tiles, 106 more tiles. Each nearshore
# product carries its OWN local vertical datum, not NAVD88: HI=MSL, PR=PRVD02,
# USVI=VIVD09, Guam=GUVD04, AmSam=ASVD02, CNMI=NAVD88 (all local-MSL-family, verified
# in the tile headers). NoData varies per tile (-9999 / -999999); gdalwarp reads each
# tile's nodata + CRS at reproject, so they ingest as-is exactly like CONUS. PR/USVI are
# inside VDatum coverage and correct with the rest; Hawaii and the Pacific territories
# have no VDatum grid at all and stay on their own local datum until per-island scalars
# land — that's why the header keeps the per-territory datum on record.
