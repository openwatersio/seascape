# NOAA CUDEM 1/3 arc-second, American Samoa — a *filelist* (manifest), not a data file:
# the line below is an NCEI urllist the engine fetches, 7 tiles over Tutuila and the
# Manu'a group. The offshore/deeper band that telescopes out beyond the 1/9 nearshore
# zone, and a separate source id from cudem_pacific_samoa because the zoom cap follows
# the resolution (z12 vs z13). NAD83 (EPSG:4269) horizontal on every tile, nodata -999999.
# The headers declare NAVD88 height (EPSG:5703), which has no realization in American
# Samoa — NGS defines ASVD02, which the 1/9 band declares over the same islands — so the
# label carries no information about the actual frame. That is on top of the reason the
# 1/9 band is uncorrected (no published tie from any local datum to MLLW at Pago Pago,
# whose datums sit on a post-earthquake 2011-2019 epoch), so this band carries no
# `datum_offset_m` either.
