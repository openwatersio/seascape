# NOAA CUDEM, American Samoa — a *filelist* (manifest), not a data file: each line below is an
# NCEI urllist the engine fetches, 14 tiles over Tutuila and the Manu'a group (lon
# -171.0..-169.25, lat -14.5..-14.0), in both published bands: 1/9 arc-second (~3.4 m, 8112²
# tiles) nearshore and 1/3 arc-second (~10 m, 2712² tiles) telescoping out beyond it. Build
# depth is derived per FILE from its own pixel size, so both bands live in one source and the
# merge orders the finer files first. NAD83 (EPSG:4269) horizontal on every tile, vertical
# ASVD02 height (EPSG:6643) at 1/9 and a declared NAVD88 height at 1/3 — which has no
# realization in American Samoa at all, so that label carries no information about the frame.
# NoData -999999.
# Alone among the Pacific territories this source carries no `datum_offset_m`: Pago Pago
# 1770000 is the only station, it publishes no ASVD02 row to tie the DEM's own datum to MLLW,
# and its datums sit on a modified 2011-2019 epoch rather than the 1983-2001 NTDE every other
# Pacific station uses — the signature of the post-2009-earthquake re-determination, whose
# subsidence offsets ASVD02 from present-day MSL by an unmeasured amount. A scalar here would
# be a guess with an unbounded sign, so the ~0.4 m deep bias stays documented instead. The
# Manu'a group has no station at all, 100 km from Tutuila.
