# NOAA CUDEM 1/9 arc-second, Pacific territories — a *filelist* (manifest), not a data
# file: each line is an NCEI urllist the engine fetches, 71 tiles across Hawaii, Guam,
# CNMI and American Samoa. These sit apart from the mainline `cudem` source because their
# HORIZONTAL frames genuinely differ — Hawaii is WGS 84 (EPSG:4326), Guam is NAD83(MA11)
# (EPSG:6325), CNMI/AmSam are NAD83 (EPSG:4269) — which is what `mixed_crs: true` is for;
# CONUS+AK+PR/USVI are uniformly EPSG:4269 and take the cheaper single-VRT path.
# Vertical is a local island datum per territory (HI=MSL, AmSam=ASVD02, CNMI=NAVD88, Guam
# declares none) and VDatum publishes no grid out here, so nothing is corrected: depths
# stay on their own ~MSL-family datum until per-island scalars land. NoData varies per
# tile (-9999 / -999999) and each file's header carries it.
